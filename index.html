AutoHS capabilities

What the first NeuroInsight-AutoHS application delivers (same core workflow as the AutoHS CLI).

FreeSurfer Integration

Industry-standard automated cortical reconstruction and subcortical segmentation for reliable hippocampal identification.

Volumetric Analysis

Precise measurement of left and right hippocampal volumes in mm³ with statistical reliability assessment.

Asymmetry Detection

Automated hippocampal asymmetry indices using thresholds described in the AutoHS publication for research screening.

Rapid Processing

Automated pipeline delivers results faster without manual intervention, typically completing analysis within hours.

What is NeuroInsight?

NeuroInsight hosts reproducible neuroimaging workflows on your infrastructure. Each workflow has a pipeline (e.g. AutoHS) and an application tool (NeuroInsight-AutoHS today).

Research software only—not FDA-cleared. For the published method, software links, and MATLAB scripts, see Research & publications.
