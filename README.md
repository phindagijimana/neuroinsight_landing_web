# NeuroInsight Landing Page

Public site for the **NeuroInsight** platform—automated neuroimaging **workflows**. **AutoHS** is the first workflow; **NeuroInsight-AutoHS** is the application that runs it.

## Live Site

- **Home:** https://phindagijimana.github.io/neuroinsight_landing_web/
- **Research:** https://phindagijimana.github.io/neuroinsight_landing_web/research.html
